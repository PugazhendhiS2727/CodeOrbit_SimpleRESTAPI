# CodeOrbit Simple REST API

This project was developed as part of the CodeOrbit Tech Backend Development Internship.

## Features
- GET all notes
- POST a new note
- PUT (update) a note
- DELETE a note
- JSON file storage
- Built using Node.js and Express.js

## Technologies Used
- Node.js
- Express.js
- Postman

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /notes | Get all notes |
| POST | /notes | Add a new note |
| PUT | /notes/:id | Update a note |
| DELETE | /notes/:id | Delete a note |
